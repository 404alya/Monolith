# models: test package

Not a level: a small package that uses every kind of map statement once (textured, shader and
plain materials; model instances with overrides, per-slot materials, collision boxes; shadowed
and unshadowed lights; spawn and viewpoints). `tools/leakcheck.sh` loads, draws, reloads,
exports and submits requests on it. Keep it small and self-contained (CC0 assets only).
